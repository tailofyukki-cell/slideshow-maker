# SlideshowMaker

音声ファイルと画像または動画ファイルを、ファイル名に基づいて自動で組み合わせ、1本のMP4動画として出力するWindows向けデスクトップアプリケーションです。テロップ、複数画像、BGMミックス、オーディオビジュアライザーなどにも対応します。

## 主な機能

| 機能 | 概要 |
|---|---|
| 自動ペアリング | 同じベース名の音声と画像／動画を自動で対応付けます。 |
| 複数画像・タイミング制御 | `_001`、`_002` の連番画像とTiming JSONを使い、1音声内の画像切替を制御できます。 |
| テロップ | JSONで文字、表示位置、装飾、アニメーションを指定できます。 |
| BGMミックス | 音声音量とBGM音量を個別に設定し、BGMを動画尺までループ再生できます。 |
| ビジュアライザー | 波形、周波数バー、スペクトログラム、ベクタースコープを重ねられます。 |
| プロジェクト保存・読込 | 入力フォルダ、出力先、演出、BGMなどの設定を再利用できます。 |
| GUI／CLI | 通常操作用のGUI版と、バッチ処理向けのCLI版を使い分けられます。 |

## 動作環境

Windows 10 / 11（64bit）で利用できます。`ffmpeg.exe` と `ffprobe.exe` を、生成したEXEと同じフォルダへ置いてください。

## GUI版の使い方

### 1. 素材を用意する

音声ファイルと画像または動画ファイルを同じフォルダに置き、**拡張子を除いたファイル名を一致**させます。

```text
my_folder/
├── 001.mp3
├── 001.jpg
├── chapter02.wav
├── chapter02.png
└── _bgm.mp3              # 任意：全体へ流すBGM
```

### 2. 動画を生成する

1. `SlideshowMaker.exe` をダブルクリックして起動します。GUI版ではコマンドプロンプトは表示されません。
2. 「**① 入力フォルダ選択**」から素材フォルダを指定します。自動的にスキャンが行われます。
3. 「**② ファイルペア一覧**」で、緑色の完全ペア（音声＋画像／動画）を確認します。
4. 「**③ 出力設定**」で、出力先と演出を設定します。
5. 「**④ 動画生成**」の「動画を生成する」をクリックします。

| 設定項目 | 内容 |
|---|---|
| 解像度 | YouTube横型、TikTok／Reels縦型、Instagram正方形などのプリセットを選択します。 |
| ケン・バーンズ効果 | 静止画に緩やかなズーム・パンを加えます。 |
| ファイル名タイトル | 各チャプター先頭のファイル名タイトル表示をON／OFFできます。 |
| ビジュアライザー | スタイル、高さ、不透明度、単色／レインボー／ファイア／ネオン／ゴールドを選べます。 |
| BGMミックス | BGMの指定、音声音量・BGM音量、開始オフセット、フェードを設定できます。 |

## プロジェクト保存・読込

画面上部の「**プロジェクトを保存...**」をクリックすると、現在の制作設定を `.slideshow.json` ファイルとして保存できます。「**プロジェクトを読込...**」をクリックすると、その設定を再び画面へ復元し、入力フォルダが存在する場合は自動で再スキャンします。

保存対象は以下です。音声・画像・動画などの**素材ファイル自体はプロジェクトへコピーされません**。

| 保存される項目 | 内容 |
|---|---|
| 素材・出力パス | 入力フォルダ、出力MP4、BGMファイルのパス |
| 出力設定 | 解像度、ケン・バーンズ、タイトル表示 |
| ビジュアライザー設定 | 有効／無効、スタイル、高さ、不透明度、色モード、単色の色 |
| BGM設定 | 有効／無効、音声・BGM音量、開始オフセット、フェードイン／アウト |

> プロジェクトファイルを素材フォルダ内、またはその親フォルダ内に保存すると、同じフォルダ階層内のパスは相対パスで記録されます。素材フォルダとプロジェクトファイルをまとめて移動した場合も、読込時にパスを復元しやすくなります。

### 推奨手順

1. 入力フォルダを選択し、出力設定を調整します。
2. 「プロジェクトを保存...」から、たとえば `my_song.slideshow.json` として素材フォルダ内に保存します。
3. 後日修正するときは「プロジェクトを読込...」で開き、設定変更後に再保存・再生成します。

## BGMミックス

「BGMをミックスする」を有効にし、BGMファイルを参照から指定します。入力フォルダに `_bgm.mp3`、`_bgm.wav`、`bgm.mp3` などを置いておけば、自動検出も可能です。BGMは動画の長さに合わせてループし、最終出力時に音声とミックスされます。

同じフォルダに `_bgm_timing.json` を置くと、BGMの設定をファイル側で指定できます。

```json
{
  "start_offset": 10.0,
  "fade_in": 2.0,
  "fade_out": 5.0,
  "volume": 0.3
}
```

## CLI版の使い方

`SlideshowMakerCLI.exe` はコンソール表示ありのコマンドライン専用アプリです。GUI版と異なり、**`--cli` は不要**です。

```cmd
REM ヘルプと解像度一覧
SlideshowMakerCLI.exe --help
SlideshowMakerCLI.exe --list-presets

REM 基本的な動画生成
SlideshowMakerCLI.exe --input C:\Music\MyAlbum --output C:\out\album.mp4

REM タイトル非表示、ケン・バーンズ、レインボー波形
SlideshowMakerCLI.exe --input C:\Songs --output C:\out.mp4 --no-title --ken-burns --visualizer waveform

REM BGMを明示指定して音量を調整
SlideshowMakerCLI.exe --input C:\Songs --output C:\out.mp4 --bgm C:\bgm\music.mp3 --voice-vol 1.0 --bgm-vol 0.3

REM BGMのイントロ10秒をスキップし、フェードを設定
SlideshowMakerCLI.exe --input C:\Songs --output C:\out.mp4 --bgm C:\bgm\music.mp3 --bgm-offset 10 --bgm-fade-in 2 --bgm-fade-out 5

REM スキャンだけ実行する
SlideshowMakerCLI.exe --input C:\Songs --dry-run
```

| オプション | 内容 | デフォルト |
|---|---|---|
| `--input FOLDER` / `-i` | 素材フォルダ | 必須 |
| `--output FILE` / `-o` | 出力MP4 | `<入力フォルダ>\output.mp4` |
| `--preset NAME` / `-p` | 解像度プリセット | 1080p横型 |
| `--width`、`--height` | カスタム解像度 | 未指定 |
| `--no-title` | ファイル名タイトルを非表示にする | OFF |
| `--ken-burns` | 静止画のズーム・パンを有効にする | OFF |
| `--visualizer STYLE` | `waveform`、`freqbar`、`spectrum`、`vectorscope` | OFF |
| `--bgm FILE` | BGMファイル。省略時はフォルダ内の`_bgm.*`を自動検出 | 未指定 |
| `--voice-vol` | 音声音量倍率（0.0〜2.0） | 1.0 |
| `--bgm-vol` | BGM音量倍率（0.0〜2.0） | 0.5 |
| `--bgm-offset` | BGM開始オフセット（秒） | 0.0 |
| `--bgm-fade-in` / `--bgm-fade-out` | BGMフェード時間（秒） | 1.0 / 2.0 |
| `--dry-run` | スキャンのみ実行 | OFF |
| `--verbose` / `-v` | 詳細ログを表示 | OFF |

## 高度な素材指定

### 複数画像モード

1つの音声に複数画像を使う場合、画像名へ `_001`、`_002` の連番を付けます。完全一致する画像（例：`001.png`）がある場合は、完全一致が優先されます。

```text
001.mp3
001_001.png
001_002.png
001_003.png
```

### Timing JSON

`{ベース名}_timing.json` を置くと、複数画像の表示時間を指定できます。

```json
[
  {"image": "001_001.png", "duration": 10.0},
  {"image": "001_002.png", "duration": 15.0},
  {"image": "001_003.png", "duration": 5.0}
]
```

### テロップJSON

`{ベース名}.json` を置くとテロップを追加できます。

```json
[
  {
    "text": "テロップテキスト",
    "start": 1.0,
    "end": 4.0,
    "position": "bottom",
    "size": 60,
    "color": "white",
    "animation": {"type": "fade", "in_duration": 0.5, "out_duration": 0.5}
  }
]
```

## よくある問題

| 症状 | 対処 |
|---|---|
| 完全ペアが0件 | 音声と画像／動画の拡張子を除くファイル名が一致しているか確認します。 |
| FFmpegが見つからない | `ffmpeg.exe` と `ffprobe.exe` を実行ファイルと同じフォルダに配置します。 |
| プロジェクト読込後に素材が見つからない | 素材フォルダを選択し直してスキャンします。可能ならプロジェクトファイルを素材フォルダ内または親フォルダに保存します。 |
| 出力先へ書き込めない | 出力先フォルダのアクセス権限を確認し、別の保存先を指定します。 |

## 開発者向け：Windows EXEのビルド

Windows 10 / 11とPython 3.9以上を用意し、ソースフォルダで `build_windows.bat` を実行します。依存パッケージのインストール後、以下の2つが `dist` フォルダに生成されます。

| ファイル | 用途 |
|---|---|
| `SlideshowMaker.exe` | GUI版。コマンドプロンプトを表示せずに起動します。 |
| `SlideshowMakerCLI.exe` | CLI版。コマンドプロンプトで引数と進捗を扱います。 |

技術スタックはPyQt5、mutagen、FFmpeg、PyInstallerです。
