GUIモード — 出力設定の詳細

③ 出力設定で動画の見た目を細かくカスタマイズできる

設定項目 内容 選択肢
解像度プリセット 動画の縦横サイズ YouTube横型(1920×1080) / TikTok縦型(1080×1920) / Instagram正方形(1080×1080) / 4K / 720p 等6種類
ケン・バーンズ効果 静止画にズーム・パン動作を追加 ON / OFF
ファイル名タイトル表示 各チャプター先頭にファイル名を白文字でオーバーレイ ON（デフォルト）/ OFF
オーディオビジュアライザー 音声波形を動画に透かしとして重ねる OFF / 波形 / 周波数バー / スペクトログラム / ベクタースコープ
ビジュアライザーカラー ビジュアライザーの色テーマ 単色（カラーピッカー）/ レインボー / ファイア / ネオン / ゴールド
出力先ファイル 生成するMP4のパス デフォルト: 入力フォルダ内の output.mp4
