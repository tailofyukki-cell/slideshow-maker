事前準備 — ファイルの配置ルール

音声と画像は「同じファイル名（拡張子なし）」でペアにする

SlideshowMakerは、拡張子を除いたファイル名が一致する音声と画像を自動的にペアとして認識します。

注意点と対応形式
  • 全角・半角の違いも別ファイルとして扱われます。
  • 音声のみ・画像のみのファイルはスキャン結果に表示されますが、動画生成の対象外となります。
  • 対応音声: MP3 / WAV / FLAC / OGG / AAC / M4A / WMA
  • 対応画像: JPG / PNG / WebP / AVIF / BMP / TIFF / GIF（アニメーション対応）
  • 対応動画（ビジュアル素材）: MP4 / MOV / AVI / MKV / WebM / FLV / WMV
フォルダ構成例
my_folder/
├── 001.mp3        ← 音声
├── 001.jpg        ← 対応する画像（同じ名前）
├── chapter02.mp3
├── chapter02.png
└── title_bgm.mp3  ← 画像がない場合は無視される
