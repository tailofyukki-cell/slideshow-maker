CLIモード — 主要オプション一覧

豊富なオプションでGUIと同等の設定が可能

オプション 短縮形 説明 デフォルト
--input FOLDER -i 入力フォルダのパス 必須
--output FILE -o 出力MP4ファイルのパス <入力>/output.mp4
--preset NAME -p 解像度プリセット名 1080p 横型
--width / --height — カスタム解像度（px） —
--no-title — ファイル名タイトルを非表示 表示ON
--ken-burns — ケン・バーンズ効果を有効化 OFF
--visualizer STYLE — ビジュアライザー種類 OFF
--viz-color #RRGGBB — ビジュアライザーの色 #00ffff
--fps N — フレームレート 30
--fade SEC — フェード時間（秒） 0.75
--dry-run — スキャンのみ（動画生成なし） —
--verbose -v 詳細な進捗を表示 OFF
