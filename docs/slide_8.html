高度な機能 — タイミング制御とテロップ

JSONファイルを配置するだけで表示時間・テキストオーバーレイを細かく制御できる

タイミング制御（{ベース名}_timing.json）

各画像の表示秒数を個別に指定できます。複数画像モードと組み合わせて、スライドごとの長さを調整する際に使用します。 

[
  {"image": "001_001.png", "duration": 10.0},
  {"image": "001_002.png", "duration": 15.0},
  {"image": "001_003.png", "duration": 5.0}
]
テロップ（{ベース名}.json）

動画の任意の時間帯にテキストを表示できます。フェードイン・アウトアニメーションや、表示位置・サイズ・色の指定にも対応しています。 

[
  {
    "text": "テロップテキスト",
    "start": 1.0, "end": 4.0,
    "position": "bottom", "size": 60, "color": "white",
    "animation": {
      "type": "fade", 
      "in_duration": 0.5, 
      "out_duration": 0.5
    }
  }
]
